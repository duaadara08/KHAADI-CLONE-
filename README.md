# Khaadi-Inspired E-Commerce Website

A front-end e-commerce website inspired by the design and shopping experience of Khaadi. This project was built from scratch to practice and strengthen my HTML, CSS, and JavaScript skills.

## 🌐 Live Demo

**[View the Live Website](https://duaadara08.github.io/KHAADI-CLONE/)**

## 📌 About the Project

This project is a clothing e-commerce website featuring a modern layout, product displays, navigation, and interactive elements.

The goal of this project was to gain hands-on experience building a complete front-end website and deploying it online using GitHub Pages.

## ✨ Features

* Responsive website layout
* Navigation menu
* Product listings and product displays
* Interactive JavaScript elements
* Clothing-focused e-commerce design
* Multiple website pages
* Images and visual product presentation
* Deployed using GitHub Pages

## 🛠️ Technologies Used

* **HTML5** — Website structure
* **CSS3** — Styling and layout
* **JavaScript** — Interactivity and functionality
* **Git & GitHub** — Version control and project management
* **GitHub Pages** — Website deployment

## 🚀 Running the Project Locally

1. Clone the repository:

```bash
git clone https://github.com/duaadara08/KHAADI-CLONE.git
```

2. Open the project folder.

3. Open `index.html` in your browser.
